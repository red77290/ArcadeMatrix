ArcadeMatrix Web Installer

Flash ArcadeMatrix directly from Chrome or Edge over USB.
Powered by ESP Web Tools.
⚠️
Pick the board that matches your hardware. Flashing the wrong image can boot-loop the board. See docs/HARDWARE.md if you're not sure which chip you have.
🟦

Standard ESP32

No PSRAM required. For WROOM/DevKit modules.
Supports up to 128x32 panels.

🟪

ESP32-S3 (PSRAM)

Requires a PSRAM-equipped S3 board (e.g. N8R8).
Supports up to 256x64 panels.

Binaries are rebuilt automatically from the latest main branch by CI.
