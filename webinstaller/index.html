ArcadeMatrix Web Installer

Flash ArcadeMatrix directly from Chrome or Edge over USB - no PlatformIO, no command line. Powered by ESP Web Tools (uses the WebSerial API, so it only works in Chromium-based browsers, on desktop).

⚠️ Pick the board that matches your hardware. Flashing the wrong image can boot-loop the board (it won't damage it, but you'll need to re-flash with the correct one). See docs/HARDWARE.md if you're not sure which chip you have.

Standard ESP32 (WROOM/DevKit) - up to 128x32 panels

No PSRAM required. This is the common/cheap ESP32 dev board.

ESP32-S3 (with PSRAM) - up to 256x64 panels

Requires a PSRAM-equipped S3 board (e.g. ESP32-S3-DevKitC-1 N8R8/N16R8).

Binaries are rebuilt automatically from the latest main branch by CI. See README.md in this folder for how this page is generated and hosted.
